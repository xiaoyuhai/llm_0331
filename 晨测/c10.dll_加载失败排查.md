# c10.dll 加载失败 (WinError 1114) 排查笔记

## 报错信息

```
import torch
  ...
  File "...\.venv\Lib\site-packages\torch\lib\c10.dll", 0xXXX
  OSError: [WinError 1114] 动态链接库(DLL)初始化例程失败
```

**关键点**: `c10.dll` 是 PyTorch 自带的 C++ 核心库，不是 Windows 系统文件。路径在 `.venv\Lib\site-packages\torch\lib\c10.dll`。

## 根因

VC++ 运行库版本太旧。cu128 编译的 torch (2.9.0+) 依赖较新的 **VC++ Redistributable** (2022 14.40+)，而 cu118 编译的 torch (2.5.1) 依赖旧版也能运行。

本机 NVIDIA RTX 3070, driver 591.86 (supports CUDA 12.8):
- cu118 torch (2.5.1+cu118) → 正常
- cu128 torch (2.10.0+cu128) → WinError 1114 ❌ → **升级 VC++ 后** ✅

## 解决方案

1. 下载安装最新 VC++ Redistributable:
   - https://aka.ms/vs/17/release/vc_redist.x64.exe
   - 或者从微软官网搜索 "Visual C++ Redistributable latest supported downloads"
2. 重启终端/PowerShell
3. 验证: `python -c "import torch; print(torch.__version__)"`

## 验证是否已修复

```powershell
# 查看当前 torch 版本
.venv\Scripts\python.exe -c "import torch; print(torch.__version__); print(torch.version.cuda)"
```
