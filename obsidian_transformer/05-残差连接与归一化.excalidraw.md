残差连接与归一化: Pre-Norm vs Post-Norm
Pre-Norm (现代标准: GPT, LLaMA, Qwen3)
输入 x
LayerNorm / RMSNorm
Attention / FFN
⊕
x + SubLayer(LN(x))
公式: output = x + SubLayer(LayerNorm(x))
优点: 训练稳定，允许更大学习率
Post-Norm (原始 Transformer 论文)
输入 x
Attention / FFN
⊕
x + SubLayer(x)
LayerNorm
公式: output = LayerNorm(x + SubLayer(x))
缺点: 深层次训练不稳定，需 warmup
RMSNorm: LayerNorm 的高效替代
LayerNorm:  y = γ · (x - μ) / σ + β     (需算均值 μ 和方差 σ²)

RMSNorm:     y = γ · x / RMS(x)               (仅算 RMS, 无均值)
                  RMS(x) = √(mean(x²) + ε)

⏱ RMSNorm 约快 10-15%，效果与 LayerNorm 相当
✅ Qwen3 / LLaMA 均使用 RMSNorm + Pre-Norm
你的代码实现:

class RMSNorm:
    def forward(self, x):
        rms = torch.sqrt(torch.mean(x², dim=-1, keepdim=True) + eps)
        return x / rms * self.weight
